# Web エンドポイント整理計画

- **起票日**: 2026-11-08
- **対象**: 自動生成ドキュメント、ヘルスチェック、Web コンテナ内ポート
- **ステータス**: 実装完了 (Implementation Completed)

---

## 1. 案件概要

### 背景

本番公開する Web サーバーの公開面を把握しやすくするため、利用していないヘルスチェック用エンドポイントを削除し、自動生成ドキュメントの公開を停止する。また、Web コンテナ内の待受ポートを `8080` に変更する。

### 目的

- FastAPI の `/docs`、`/redoc`、`/openapi.json` を無効化する。
- 未使用の `GET /healthz` エンドポイントとその実装・テストを削除する。
- Web サーバー、Podman Pod の転送先、ドキュメントをコンテナ内ポート `8080` に統一する。ホスト側ポート `8082` は維持する。

---

## 2. 実装方針

1. FastAPI の `docs_url`、`redoc_url`、`openapi_url` を無効化する。
2. `health_router` の登録、`homeiot/web/health.py`、対応するテストを削除する。
3. `WEB_PORT` と Quadlet の `PublishPort` のコンテナ側ポートを `8080` に変更する。
4. アーキテクチャ仕様とREADMEを現行構成に合わせて更新し、作業履歴へ本案件を追加する。
5. 過去の計画書にある当時の `/healthz` 記述は履歴として保持する。
