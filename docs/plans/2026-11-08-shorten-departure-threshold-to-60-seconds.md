# 外出判定しきい値を60秒に短縮する計画

- **起票日**: 2026-11-08
- **対象**: Presence Sensor Pro を使った外出判定しきい値の短縮
- **ステータス**: 実装完了 (Implementation Completed)

---

## 1. 案件概要

### 背景

Presence Sensor Pro の最新状態を在室判定に利用できるようになったため、スマートフォン Ping だけで判定していた時より短い時間で外出を確定できる。

### 目的

外出判定のしきい値を試験的に60秒へ短縮し、帰宅確定のしきい値は従来どおり300秒に維持する。

---

## 2. 方針

1. `OUT_THRESHOLD_SECONDS` を60秒に変更する。
2. 帰宅判定用の `ARRIVAL_THRESHOLD_SECONDS` を新設し、従来値300秒を維持する。
3. `homeiot/constants.py` をしきい値の唯一の定義箇所として保つ。
4. architecture と要件定義、境界条件のユニットテストを更新する。

---

## 3. 実装・確認記録

- [x] 外出・帰宅のしきい値を分離し、外出のみ60秒にする。
- [x] 仕様書、要件定義書、作業履歴を更新する。
- [x] 外出60秒と帰宅300秒の境界テストを追加する。
- [x] `tox -e lint` を実行する。

`tox -e lint` は成功。`tox -e unittest` は Windows 標準 Python に `pwd` モジュールがなく、`aiomysql` の import 時にテスト収集が失敗したため、追加テストは実行されていません。
