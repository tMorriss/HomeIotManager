# Webhook 公開ポート変更計画

- **起票日**: 2026-11-07
- **対象**: HomeIotManager の Webhook 公開ポート
- **ステータス**: 実装中 (Implementation in Progress)

---

## 1. 案件概要

### 背景

Webhook を受信する Web コンテナは、Podman Pod のホストポート `8930` からコンテナ内ポート `8001` へ転送している。公開ポートを `8082` に変更する。

### 目的

Quadlet のポート転送をホスト `8082` → コンテナ `8001` に変更し、README とアーキテクチャ仕様の現行情報を同期する。

---

## 2. 方針

1. `build/quadlet/homeiot.pod.template` の `PublishPort` を `8082:8001` に変更する。
2. README と `docs/architecture.md` に記載された現行ポートを `8082` に更新する。
3. 完了済み計画書および作業履歴の旧ポート記載は、当時の構成を示す履歴として保持する。
4. ホスト側 Nginx の設定はリポジトリ管理対象外のため、デプロイ時に転送先を `127.0.0.1:8082` に合わせる。
