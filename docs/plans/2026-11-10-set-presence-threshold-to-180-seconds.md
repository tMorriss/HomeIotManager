# 在室・外出判定のしきい値を180秒に変更する計画

- **起票日**: 2026-11-10
- **対象**: 在室・外出判定の共通しきい値
- **ステータス**: 実装完了 (Implementation Completed)

---

## 1. 案件概要

### 背景

PR #34 で在室・外出判定のしきい値を60秒に統一した。運用上の判定時間を3分にするため、外出・帰宅の両方で使う共通しきい値を180秒へ変更する。

### 目的

在宅状態または不在状態が3分（180秒）続いた時点で、外出・帰宅を確定する。

---

## 2. 方針

1. `OUT_THRESHOLD_SECONDS` を180秒に設定し、外出・帰宅判定の共通値として使う。
2. 要件定義書とアーキテクチャ仕様書を実装値に同期する。
3. 帰宅直後の猶予で使う `LAST_IN_THRESHOLD_SECONDS` など、独立したしきい値は変更しない。

---

## 3. PR 分割計画

本変更は単一定数と関連仕様の更新で完結するため、1つのPRで提出する。

---

## 4. 検証手順

1. `OUT_THRESHOLD_SECONDS` が180であることを確認する。
2. 要件定義書およびアーキテクチャ仕様書の説明が3分（180秒）で一致することを確認する。
3. 外出判定の境界UTが179秒では未確定、180秒では確定となることを確認する。
4. `tox -e lint` と `tox -e unittest` を実行する。
