# HomeIotManager 要件定義書 (Requirements Specification)

本ドキュメントは、HomeIotManager において実現したい要件をまとめた仕様書です。
主な要件は [docs/plans/2026-09-20-migration-from-in-out-log.md](plans/2026-09-20-migration-from-in-out-log.md) から抽出・統合されています。
システムの詳細アーキテクチャや技術仕様については [docs/architecture.md](architecture.md) を参照してください。

---

## 1. システム概要・目的

現行システム `in_out_log` は、在宅・外出の検知、照明・ルンバの自動操作、および入退室ログの記録を行っています。
今後、センサーの追加や制御ロジックの高度化など大規模な機能改修を予定していますが、現行コードベースは cron 実行やハードコードされた機密情報、レガシーなファイル構成を抱えています。

これらを解消し、今後の機能拡張を安全かつ迅速に行うため、現行の処理・ロジック・データベースを引き継いだ状態で `HomeIotManager` として再構築・移行することを目的とします。

### 主な目的・方針
1. **既存機能・DBの完全継承**:
   - 既存 MySQL のテーブル（`in_out`, `lasts`, `roomy_lock`）およびデータをそのまま継続利用する。
   - SQL クエリはプレースホルダ（パラメータバインド）を用いた安全な実装に刷新する。
2. **パブリックリポジトリとしてのセキュリティ確保**:
   - リポジトリは GitHub public で公開するため、機密情報（DB接続情報、トークン、LAN内IP）は一切リポジトリ内に保持しない。
   - Jenkins 側の Credentials で環境変数を保持し、デプロイ時に注入する。
3. **Podman Pod マルチコンテナ構成への移行**:
   - Web サーバー（ポート 8930）と Worker（常駐バッチループ / 10秒間隔）を 1つの Podman Pod（`hostNetwork: true`）で稼働させる。
4. **設定の2層分離**:
   - 機密情報は環境変数化。
   - 動作パラメータ（10秒インターバル、各種しきい値、時間帯など）は環境変数化せず、`homeiot/constants.py` の 1箇所に集約管理する。

## 2. 機能要件

### 2.1 在宅 / 外出自動判定
- **スマートフォンの ICMP Ping 監視**:
  - 宅内 LAN 上の対象スマートフォンの IP アドレスに対して定期的に ICMP Ping を送信し、Wi-Fi 接続状態（在宅/外出）を判定する。
- **人感センサー Webhook 連携**:
  - SwitchBot 人感センサー（`WoPresence`）からの Webhook イベントを受信・解析し、スマホ未在宅時の反応を検知して即時に帰宅判定を行う。
- **判定ロジック**:
  - 定められたしきい値時間（例: 5分）をもとに、一時的な通信切断等による誤判定を防ぎつつ、確実な在宅・外出状態の遷移を行う。

### 2.2 スマート家電自動制御
- **帰宅時自動制御**:
  - 帰宅判定時、時間帯（例: 17:00〜06:00）に応じた照明（Philips Hue、シーリングライト）の自動点灯を行う。
  - ルンバが清掃稼働中の場合は自動帰還（Dock）させる。
- **外出時自動制御**:
  - 外出確定時、一定時間（例: 10分）経過後に自動消灯を行う。
  - 日中時間帯かつ当日の未清掃時、およびルンバ稼働禁止時間外・抑制日でない場合に、ルンバの自動清掃（IFTTT 経由）を開始する。

### 2.3 ルンバ稼働抑制・Web UI
- **稼働抑制日（Lock）管理**:
  - ルンバの自動起動を一時的に停止したい日付を指定・管理する機能を提供する。
  - MySQL の `roomy_lock` テーブルに設定日を保持し、指定日以前は自動起動を行わない。
- **Web UI インターフェース**:
  - ポート 8930 で稼働する Web サーバー上に、ルンバ稼働抑制日の確認および更新・解除が行える設定画面（`/settings`）を提供する。

### 2.4 入退室ログ記録
- **イベント履歴の永続化**:
  - 在宅（帰宅）および外出イベントの発生日時を MySQL の `in_out` テーブルにログとして永続化する。
- **状態日時の更新**:
  - 最終在宅時間、最終外出時間、最終ルンバ稼働日時、最終消灯日時などの状態を `lasts` テーブルに記録・保持する。
