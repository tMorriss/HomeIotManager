# HomeIotManager 要件定義書 (Requirements Specification)

本ドキュメントは、HomeIotManager において実現したいビジネスロジック・業務要件をまとめた仕様書です。
システムの詳細アーキテクチャや技術実装仕様については [docs/architecture.md](architecture.md) を参照してください。

---

## 1. システム概要・目的

HomeIotManager は、居住者の在宅・外出の自動判定、照明や掃除ロボット（ルンバ）の自動制御、および入退室ログの記録を行うスマートホーム統合管理システムです。

---

## 2. 機能要件

### 2.1 在宅 / 外出自動判定
- **居住者の在宅・外出検知**:
  - 居住者のスマートフォンが自宅 Wi-Fi に接続されているかどうかの状態を定期的に確認し、在宅か外出かを判定する。
  - スマートフォンが未接続（外出）の状態であっても、人感センサーが反応した場合は即座に「帰宅」と判定する。
- **誤判定防止としきい値判定**:
  - 一時的な通信途絶などによる誤判定を防ぐため、在宅・外出の判定変更には時間的なしきい値（例: 5分）を設けて状態遷移を行う。
  - 在宅・外出判定のしきい値とは別に、照明制御などの自動制御用しきい値（例: 10分）を独立して保持・判定する。

### 2.2 スマート家電自動制御
- **帰宅時の自動制御**:
  - 帰宅と判定された際、対象時間帯（夕方〜早朝）であれば、居室の照明（Philips Hue、シーリングライト）を自動的に点灯する。
  - 掃除ロボットが清掃中の場合は、人の帰宅を検知して清掃を中断し、自動的に充電ドックへ帰還させる。
- **外出時の自動制御**:
  - 在宅状態から不在になって外出が確定した後、最終在宅時刻からの経過時間が照明制御用しきい値（例: 10分）を超えた段階で、今回の外出で未消灯であれば居室の照明を自動的に消灯する。
  - 外出の度（1回の外出につき1回）、日中時間帯かつ稼働禁止時間帯や稼働抑制日でなければ、外出をトリガーとして掃除ロボットの自動清掃を開始する。

### 2.3 ルンバ稼働抑制
- **掃除ロボットの自動起動抑制**:
  - 在宅勤務や休日等で掃除ロボットの自動起動を一時的に止めたい日のために、稼働抑制日を指定できる機能を提供する（※DBテーブル `roomy_lock` および判定ロジックは保持しますが、保守コスト削減のため Web UI 設定画面は非搭載とします）。
  - 抑制日として設定された日（または指定日以前）は、外出時であっても掃除ロボットの自動起動を行わない。

### 2.4 入退室ログ記録
- **入退室・状態変更履歴の保存**:
  - 帰宅および外出が発生した日時を履歴として保存する。
  - 最終帰宅日時、最終外出日時、最終清掃日時、最終消灯日時などの最新状態日時を記録・保持する。
